# Icon source and adaptation — October 1, 2026

The owner prohibited hand-drawn or improvised icon glyphs after identifying the off-center CSS circle-plus on the Learning cards. Its replacement and the other small pictorial controls in this revision use exact Lucide components.

- Approved X reference: [Nero’s icon-resource bookmark](https://x.com/neropursue/status/2099827788521889995), captured in `research/x/x-024/post.json`, explicitly links to [Lucide Icons](https://lucide.dev/icons).
- Exact Lucide components: [Plus](https://lucide.dev/icons/plus), [Minus](https://lucide.dev/icons/minus), [ChevronDown](https://lucide.dev/icons/chevron-down), [Menu](https://lucide.dev/icons/menu), [X](https://lucide.dev/icons/x), [BookOpen](https://lucide.dev/icons/book-open), [Sun](https://lucide.dev/icons/sun), [UsersRound](https://lucide.dev/icons/users-round), and [ArrowUpRight](https://lucide.dev/icons/arrow-up-right). MotionSites' saved [3D Story specification](../../research/motionsites/motion-010/source-prompt.txt) calls for Lucide ChevronDown, independently supporting this particular glyph.
- Placement: small ChevronDown beside text-led Learning and scholarship quote cues, the chapter bookmark, and resource document groups; Plus/Minus in other detail disclosures; Menu/X in the navigation trigger and dismiss action; BookOpen, Sun and UsersRound beside related program cues; ArrowUpRight on the site button.
- Adaptation: only color, rendered size and surrounding spacing change to match Beyond Limits navy, muted blue and gold. Glyph paths and proportions come from the Lucide package. Labels and `aria-expanded` communicate the controls’ meaning independently of the icons.

The overall Beyond Limits website direction remains grounded in the previously recorded MotionSites and X references. Lucide as a family is supported by Nero's X bookmark; ChevronDown is also specified in MotionSites' 3D Story. The other exact glyphs are from Lucide, not claimed as individually visible in a MotionSites mockup.

October 1 refinement: the owner rejected the large repeated CirclePlus controls and a chapter bookmark carrying a plus with five progress marks. The Learning cards use a quiet `Read more` text affordance with a 15px exact Lucide ChevronDown; the header bookmark shows only the chapter number, name and 13–14px ChevronDown. Removed the redundant five-mark meter. After visual feedback showed that the same oversized pattern remained in scholarship recipient rows, these now place an underlined `Read quote` cue and 14px ChevronDown directly beneath each recipient's name and grade. Resource groups use one 16px ChevronDown. The whole row remains a large tap target; icons are no longer the primary visual signal. This changes hierarchy and surrounding treatment, never the icon paths.
